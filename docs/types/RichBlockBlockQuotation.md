#🔮 RichBlockBlockQuotation

**This object represents a block quotation rich block.**

##⚙️ Properties

- **`type`** (**`str`** ): **Type of the rich block**
- **`text`** (**`RichText`** ): **Rich text**
- **`can_collapse`** (**`bool`** ): **Optional. Whether the quotation can be collapsed**
- **`fallback`** (**`str`** ): **Optional. Fallback text**
