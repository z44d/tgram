#🔮 InputPollOptionMedia

**Represents a media to be added to a poll option.**

##⚙️ Properties

- **`type`** (**`str`** ): **Type of the media**
- **`media`** (**`Path` or `str`** ): **File to send. Pass a file_id to send a file that exists on the Telegram servers (recommended), pass an
HTTP URL for Telegram to get a file from the Internet, or pass "attach://<file_attach_name>" to upload a new one**
