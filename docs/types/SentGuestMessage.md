#🔮 SentGuestMessage

**Describes a sent guest message.**

##⚙️ Properties

- **`message_id`** (**`int`** ): **Unique identifier of the sent message**
- **`sender_chat`** (**[Chat](Chat.md)** ): **Optional. The chat from which the message was sent**
- **`date`** (**`int`** ): **Date the message was sent in Unix time**
