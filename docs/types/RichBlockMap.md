#🔮 RichBlockMap

**This object represents a map rich block.**

##⚙️ Properties

- **`type`** (**`str`** ): **Type of the rich block**
- **`latitude`** (**`float`** ): **Latitude**
- **`longitude`** (**`float`** ): **Longitude**
- **`heading`** (**`int`** ): **Optional. Heading**
- **`zoom`** (**`int`** ): **Optional. Zoom level**
