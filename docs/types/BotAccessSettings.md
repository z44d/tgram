#🔮 BotAccessSettings

**This object describes the access settings of a bot.**

##⚙️ Properties

- **`is_access_restricted`** (**`bool`** ): **True, if only selected users can access the bot. The bot's owner can always access it.**
- **`added_users`** (**List of [User](User.md)** ): **Optional. The list of other users who have access to the bot if the access is restricted.**
