#🔮 InputMediaLocation

**Represents a location to be sent.**

##⚙️ Properties

- **`latitude`** (**`float`** ): **Latitude of the location**
- **`longitude`** (**`float`** ): **Longitude of the location**
- **`horizontal_accuracy`** (**`float`** ): **Optional. The radius of uncertainty for the location, measured in meters; 0-1500**
- **`live_period`** (**`int`** ): **Optional. Period in seconds for which the location will be updated**
- **`heading`** (**`int`** ): **Optional. For live locations, a direction in which the user is moving, in degrees; 1-360**
- **`proximity_alert_radius`** (**`int`** ): **Optional. For live locations, a maximum distance for proximity alerts about approaching another chat member, in meters**
