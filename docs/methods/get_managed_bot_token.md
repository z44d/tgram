#🔧 get_managed_bot_token

**Use this method to get the current bot token for a managed bot.**

##⚙️ Parameters

- **`managed_bot_user_id`** (**`int`** )

##📲 Returns

#### `str`

##📀 Examples

-🪫 **Required Parameters**

```python
await bot.get_managed_bot_token(
    managed_bot_user_id=your_managed_bot_user_id_here
)
```
