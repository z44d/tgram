#🔧 save_prepared_keyboard_button

**Stores a keyboard button that can be sent by a user of a Mini App. Returns a PreparedKeyboardButton object.**

##⚙️ Parameters

- **`user_id`** (**`int`** )
- **`button`** (**[PreparedKeyboardButton](../types/PreparedKeyboardButton.md)** )

##📲 Returns

#### [PreparedKeyboardButton](../types/PreparedKeyboardButton.md)

##📀 Examples

-🪫 **Required Parameters**

```python
await bot.save_prepared_keyboard_button(
    user_id=your_user_id_here,
    button=your_button_here
)
```
